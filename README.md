# FITNESS — تدريب لياقة أونلاين

موقع ثابت باللغتين العربية والإنجليزية، مبني باستخدام HTML5 وCSS3 وJavaScript دون أطر أو خدمات خارجية لازمة للتشغيل. زر اللغة في كل صفحة ينقلك إلى الصفحة نفسها باللغة الأخرى.

## التشغيل

افتح `index.html` في المتصفح، أو شغّل خادمًا محليًا بسيطًا داخل هذا المجلد مثل `python -m http.server 8000` ثم افتح `http://localhost:8000`.

## الملفات

- `index.html` الصفحة الرئيسية العربية، وتبدأ بحاسبة تجمع العمر والوزن والطول والتقسيمة والهدف والمستوى، ثم تعرض جدولًا مناسبًا مباشرة.
- `about.html` صفحة «من نحن» بالعربية.
- `services.html` صفحة البرامج والخدمات بالعربية.
- `plans.html` تقسيمات حسب عدد أيام التدريب والهدف، مع مكتبة رسوم وفيديوهات تمارين.
- `contact.html` صفحة تواصل تعرض حساب إنستجرام الرسمي فقط.
- `en/` النسخ الإنجليزية لجميع الصفحات، بما فيها الخطط والجداول.
- `styles.css` الهوية والتصميم المتجاوب.
- `script.js` قائمة الهاتف، حركات الظهور، التحقق من النموذج، وإنشاء جدول التمرين من اختيارات المستخدم دون حفظ بياناته أو إرسالها.
- `assets/exercise-illustrations.svg` رسوم توضيحية أصلية للحركات الأساسية، مع فيديوهات مضمّنة من NHS وفرق علاج طبيعي. لا يُحمّل الفيديو إلا عند فتحه.
- `assets/online-coaching-duo.png` صورة خلفية جديدة تعرض متدربة ومتدربًا معًا في تدريب منزلي.
- `assets/fitness-logo-source.jpg` ملف الشعار المرفق كما هو.

## قبل النشر

الموقع يعرض خدمة تدريب أونلاين، دون مقر أو زيارات حضورية. صفحة البداية تعرض جدولًا عامًا بحسب الهدف والتقسيمة ومستوى الخبرة؛ لا تعرض وزنًا مثاليًا أو سعرات، وتستخدم BMI للبالغين بعمر 20+ كمرجع فرز توعوي فقط. التواصل في الموقع عبر حساب Instagram الرسمي فقط: https://www.instagram.com/coachingfitnessonline/.
